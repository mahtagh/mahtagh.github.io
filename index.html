C# · .NET · Research · LSMR, University of Calgary

Change-Impact Analysis for DevSurge

74.8% F179.3% recall · 70.8% precision (best configuration, evaluated Java system)
Read the thesis
Problem
Text search shows where a name appears in a codebase, but not what a change will actually affect.
What I built
Integrated ModCP into the DevSurge C# Windows application using the Mediator pattern, combining lexical search with structural analysis to trace data-flow and control-flow impact. Added dependency analysis, cycle detection, graph, tree and code views, and Jira export.
Result
Raised change-impact detection recall from 21.8% to 48.2% (2.2× the baseline). The best configuration reached 74.80% F1 (79.31% recall, 70.77% precision) on the evaluated Java system.

Problem
Historical asset records were spread across spreadsheets and thousands of supporting PDFs, and publishing them to the map was slow, manual work.
What I built
Python and Excel automation to extract, standardize, validate and publish the records, with data-quality checks and exception reporting.
Result
Reviewed 1,713 records and 7,494 PDFs, verified 394 assets and published 254 to the GIS map, and made Excel-to-map uploads about 10× faster. Presented at the City of Calgary GIS Summer Student Showcase.
